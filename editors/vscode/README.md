# NextLang for Visual Studio Code & Antigravity IDE

Official NextLang extension providing syntax highlighting, file icons, and language configuration for `.nx` source files.

## Features

- **File Icon**: Displays the official NextLang fox emblem next to all `.nx` files in the explorer sidebar and editor tabs.
- **Syntax Highlighting**: Comprehensive TextMate grammar for variables (`var`, `const`, `tem`), low-level types (`INT8..128`, `USIZE`, `ISIZE`, `PTR`), OOP constructs (`class`, `interface`, `init`, `self`, `super`), control flow (`fr`, `As`, `otherwise`, `skip`, `halt`), bitwise operators, and built-in runtime functions.
- **Language Configuration**: Auto-closing pairs, comment toggling (`//`), and bracket matching.

## Installation

This extension is located in `editors/vscode` and is symlinked into `~/.vscode/extensions/nextlang-vscode`.
Restart or reload your editor to activate changes.
